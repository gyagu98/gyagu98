## Reproducible analysis projects

- [RNA-seq Nextflow workflow](https://github.com/gyagu98/rna-seq-nextflow-pipeline):
  DSL2 modules connecting FastQC, Salmon and MultiQC, with small workflow fixtures.
  [A draft update](https://github.com/gyagu98/rna-seq-nextflow-pipeline/pull/1)
  replaces placeholder differential-expression summaries with tximport/DESeq2.
  Real-cohort and complete workflow validation remain in progress.
- [Single-cell PBMC analysis](https://github.com/gyagu98/single-cell-rna-seq-pbmc3k):
  a Scanpy workflow for QC, clustering, marker inspection and heuristic cell annotation.
  This is a single-donor demonstration, not a disease or multi-donor inference study.
